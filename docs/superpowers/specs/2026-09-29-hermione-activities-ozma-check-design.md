# Гермиона: ежедневная проверка «активность на сегодня заведена в Озме»

Дата: 2026-09-29

## Проблема

В базе Notion «🎯 Активности» (ds `34a612c7-62af-80b6-85e6-000bdf26af93`) у карточки есть только дата отправки,
срока подготовки нет. Письма и бот-рассылки иногда доходят до дня отправки, а кампании в Озме
(`marketing.campaigns`) под них никто не завёл. Пример: ACT-636 «письмо про Head» на 28.09 — пустая
карточка «запланировано», кампании нет, никто не заметил.

## Решение

Гермиона (@gs_marketing_bot, `/home/agentbot/bots/hermione/bot.py`, systemd `hermione-bot`) каждый день
(включая выходные) в 12:00 МСК сама проходит по карточкам на сегодня, ищет под каждую кампанию в Озме и, если не нашла, тегает
Веронику (@korobnk) в общей теме форума «Bella & Гермиона Маркетинг» (чат `-1003936305014`, общая тема
= без `message_thread_id`, ссылка t.me/c/3936305014/1).

### Какие карточки

- «Тип канала» = `mail`. Бот-каналы (`бот-главный`, `bot-*`) не проверяем: с 12.06.2026 бот-рассылки в Озме
  не заводятся вовсе (последние `pm.actions` типа «Рассылка в боте GS» с `from_campaign` — 12.06), проверка
  давала бы тревогу по каждой карточке. Соцсети/посты в Озме не живут.
- «Дата» (по московскому времени) = сегодня.
- «Статус» ≠ «архив».
- **Каждый день, включая выходные.** Общее правило Гермионы «по выходным в чат не пишем» (`stats_scheduler`)
  на этот пинг НЕ распространяется — иначе субботние письма пропускаются (решение Бэллы 29.09.2026).

### Когда карточка считается заведённой

Есть неудалённая кампания (`is_deleted = false`, стадия не «Отменено»), которая подходит под одно из:
1. в `name` есть `ACT-<ID карточки>` (так называет кампании сама Гермиона, дата может сдвигаться —
   ACT-635 стояла на 26.09, ушла 28.09);
2. `template_id` = «№ шаблона» карточки и `campaign_start_date` в пределах ±2 дней от даты карточки
   (так нашлись ACT-631…634 → шаблон 7797630 → кампании 2742–2755);
3. только если 1 и 2 не сработали — `campaign_start_date` ±2 дня и тема/название кампании про ТО ЖЕ письмо
   (та же тема и аудитория, а не просто тот же продукт). Служебные админские письма («Напоминание о старте»,
   «Бонусы после пробного», «Пробное занятие …», «Изменение/перенос/отмена …») не засчитываются, кроме
   карточек с «Шаблон рассылки» = adm*. Сомнение → считаем незаведённой.

Правило 3 ужесточено после первого прогона: без оговорки про админские письма Гермиона засчитала ACT-636
«письмо про Head» по админской кампании #2770 «Напоминание о старте ХЕД».

Стадия кампании не важна: черновик к вечерней отправке — норма.

### Сообщение

Если есть незаведённые — одно сообщение в общую тему:
```
@korobnk В ОЗМЕ НЕ ЗАВЕДЕНЫ ПИСЬМА НА СЕГОДНЯ

— <Активность> (<время МСК, если есть>) — https://www.notion.so/<id без дефисов>
— …
```
Если всё заведено или карточек нет — тишина: модель отвечает `NOOP`; `respond()` не шлёт ответ, чья
последняя строка — `NOOP` (страховка на случай, если модель всё же допишет рассуждения перед ним).

### Где живёт

`bot.py`, по образцу `stats_scheduler`:
- константы `ACT_CHECK_HOUR = 12`, `ACT_CHECK_KEY = "activities-check"`, `ACT_CHECK_PROMPT`;
- поток `activities_check_scheduler()` — каждый день, свежая сессия на прогон, `enqueue` в общую тему;
- `respond()`: ответ с последней строкой `NOOP` не отправляется;
- ручной запуск для теста: env `ACT_CHECK_RUN_ON_START=1`.

Только чтение (Notion + Озма). Статусы карточек не трогаем, PERSONA не меняем.

### Тест

1. Бэкап `bot.py.bak-20260929-actcheck`, `py_compile`.
2. Прогон промпта на реальных данных копией бота (без записи state): 25.09 → `NOOP` (4 письма закрыты
   по шаблону 7797630), 29.09 → `NOOP` (писем нет), 28.09 → пинг по ACT-636.
3. Рестарт сервиса, `journalctl` — «Hermione bot v3 started (…, activities check)».

## Вне охвата

- Бот-каналы (пока бот-рассылки не заводятся в Озме), соцсети, внешние выходы, мероприятия.
- Проверка содержания кампании (списки, шаблон, время) — только факт наличия.
- Напоминания заранее (накануне) — при необходимости добавить вторым шагом.
