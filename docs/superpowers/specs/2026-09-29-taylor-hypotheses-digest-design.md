# Тейлор: еженедельная сводка по гипотезам — дизайн

Дата: 29.09.2026. Формат согласован с Бэллой в чате.

## Что делаем

Тейлор Свифт (@gs_ops_bot) каждую **среду в 11:00 МСК** пишет в чат «неубиваемая тройка»
сводку по базе «🧺 Гипотезы» со страницы «🌱 Гипотезы: поливай свой урожай»
(Notion `3e2612c762af81bea34edd8eeefc1537`, база `aa4cadf00e3f4aafb036980cba44cd96`):
какие гипотезы появились за неделю и у кого, какие обновились и что именно поменялось.

## Формат сообщения

```
🌱 Гипотезы за неделю · 23–30 сентября

✨ Новые — 17
Варя Лыкова
 • Фиксация договорённостей с партнёрами — Идея, итог 10.11
 • Активность в каналах потоков лаб — Идея
Катя Романова
 • Работа с бухгалтерией
Владелец не указан
 • Необычный бумажный сертификат — Идея, итог 07.12

💫 Обновились — 2
Ника Коробова
 • Первый экран пробных на мобильных — Идея → В проверке
Юля Михайленко
 • Коммерция в инст — заполнены «Метрика и порог», ICE 7·6·8
```

- Название гипотезы — ссылка на карточку Notion (Telegram HTML).
- Группировка по людям; порядок — у кого больше пунктов, выше; «Владелец не указан» последним.
- Имя человека — поле «Человек» участка карточки (база «Участки»); нет участка — «Владелец не указан».
- У новой карточки после тире: статус и «итог ДД.ММ», что заполнено; пусто — без хвоста.
- У обновлённой — что поменялось: статус «А → Б», дата итога, ICE, заполнены/обновлены
  «Если мы… то…», «Метрика и порог», «Итог», переименование.
- Карточки, чьё название начинается с «Пример», не учитываются.
- Блока «Требуют внимания» нет (решение Бэллы).
- Если за неделю ничего — одна строка: «За неделю новых и обновлённых гипотез нет 🌱».

## Как определяем новое и обновлённое

Снимок базы (`/home/agentbot/bots/taylor/hypotheses_snapshot.json`) сохраняется после
каждой успешной отправки. На следующей неделе:

- **новые** — карточек нет в прошлом снимке;
- **обновились** — есть в снимке, и поменялось хотя бы одно отслеживаемое поле.

`last_edited_time` не используем: он меняется от любой мелочи и не говорит, что поменялось.

**Первый прогон** (снимка нет): новые = созданные за последние 7 дней, блока «Обновились» нет.

## Устройство

- Отдельный модуль `/home/agentbot/bots/taylor/hypotheses.py` — детерминированный Python
  без LLM: Notion REST API → сравнение со снимком → HTML → `sendMessage`.
  Запускается и из CLI (`--dry-run` печатает отчёт, `--send CHAT` шлёт в чат без сохранения снимка).
- `bot.py` Тейлор: в существующий `scheduler()` добавляется job `hypotheses`
  (среда, с 11:00; отметка в `state.json["sched"]["hypotheses"]` = дата, ставится только после
  успешной отправки; при ошибке — повтор через 15 мин до 14:00, потом ⚠️ Бэлле в личку).
- `.env` Тейлор: `NOTION_TOKEN` (интеграция, та же, что у Гермионы — доступ к базе проверен),
  `HYP_CHAT` — id чата «неубиваемая тройка».
- Тейлор должна быть участником чата (добавляет Бэлла); privacy mode на отправку не влияет.
