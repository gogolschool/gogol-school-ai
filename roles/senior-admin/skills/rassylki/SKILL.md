# /rassylki

## Что делает

По запросу «внеси / сверь таблицу рассылок на <период>» берёт будущие продукты из Ozma, формирует и вносит строки в Notion-таблицу регулярных рассылок (по ней администраторы делают рассылки-напоминания). По запросу «проверь / сверь рассылки» пересчитывает оплаты по уже внесённым строкам, ставит/снимает статус «Под вопросом» и маякует по порогам оплат.

## Как работает

1. Загружает актуальный мастер-промпт из Notion: page `3fa612c762af81589adcfc627018d5c8`. **Все правила — там**: источники в Ozma, типы продуктов, какие строки вносить, пороги оплат, отмены и переносы.
2. Действует строго по мастер-промпту. Перед записью в Notion — показывает сводку строк и ждёт подтверждения; перед вставкой проверяет дубли.
3. Если Notion недоступен — работает по локальной копии `references/master-prompt.cache.md` (если есть) и предупреждает, что промпт из кэша. Если нет ни Notion, ни кэша — не действует вслепую, сообщает об этом.

## Важно

- Ни один продукт не пропускать молча: незнакомый или спорный — спросить у пользователя.
- Даты пользователю — в формате `ДД.ММ.ГГГГ`.
- Не править этот файл ради изменения правил — править мастер-промпт в Notion, чтобы изменения сразу попали ко всем.
