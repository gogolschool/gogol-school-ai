# /pay-invoice — счёт → реквизиты и файл платёжки

## Как работает

1. Загружает мастер-промпт из Notion: page `415612c762af81c2bd83f23a7a05e788` («Мастер-промпт: /pay-invoice — счёт поставщика → платёжка»).
2. Читает счёт (PDF / скрин через Read) и действует строго по мастер-промпту: плательщик, блоки реквизитов, назначение по формату поставщика, ловушки НДС и УИП.
3. Собирает файл платёжки скриптом рядом со скиллом:
   ```
   python3 roles/doc-fin-ops/skills/pay-invoice/make_1c.py <input.json> ~/Downloads/платежка_<поставщик>_<ДД.ММ.ГГГГ>.txt
   ```
   Формат JSON — в шапке `make_1c.py` (`"payer": "ip"` для ИП Ромашко, `"code"` — УИП в поле 22). Ошибка проверки реквизитов → файл не создаётся, причину сказать человеку.
4. По скрину платёжки сверяет её со счётом.

Ничего не оплачивает и не отправляет сам.

## Важно

- Правила (форматы назначения поставщиков, ловушки, плательщики) живут **только в Notion**. Новый поставщик или новая ловушка → дописать в мастер-промпт, в гит не коммитить.
- В гите меняется только `make_1c.py` — когда меняется сам формат файла для банка.
- Если Notion недоступен — сказать об этом и работать по общим правилам: каждое поле отдельным code-блоком, сумма `12345.67`, всегда предупредить про ставку НДС.
